# 浏览器Web应用本地文件系统访问方案

## 1. 背景与问题

`packages/assistant` 是一个运行在浏览器中的 Web 编辑器应用。当前架构下，用户可通过 `AddProjectComponent` 使用浏览器的 **File System Access API**（`showDirectoryPicker` / `showOpenFilePicker`）导入本地文件/文件夹，构建 `AstTreeNode` 树（通过 `isLocal = true` 标记）。

**File System Access API 的局限性：**

| 问题 | 说明 |
|------|------|
| 浏览器兼容性 | 仅 Chromium 内核（Chrome/Edge）支持，Firefox/Safari 不支持 |
| 用户交互依赖 | 每次导入都需要用户手动从文件选择器选取路径，无法指定任意路径 |
| Handle 持久化 | `FileSystemHandle` 存储在 IndexedDB，但跨会话可能失效 |
| 无法访问非 Web 目录 | 不能直接访问系统任意路径，只能由用户在 picker 中导航 |
| 无法执行系统命令 | 纯浏览器环境无法启动终端进程或访问系统命令 |

**当前终端架构：** `TerminalComponent` 基于 xterm.js，通过 WebSocket 连接到**远程服务器**上的 PTY。本地导入的文件在浏览器内使用 File System Access API 读写，与终端的连接方式不一致。

---

## 2. 总体架构

引入**本地代理 Agent**（Local Proxy Agent），当 `AstTreeNode` 的根节点 `isLocal === true` 时，Web 应用的所有文件操作和终端连接均切换至本地代理 Agent。

```
┌─────────────────────┐         WebSocket          ┌────────────────────┐
│  浏览器 Web App      │◄──────────────────────────►│  本地代理 Agent     │
│  (Angular + xterm)  │                             │  (Node.js 进程)     │
│                     │  isLocal=true 时连接         │                    │
│  ContentComponent   │    ws://127.0.0.1:9120      │  ┌──────────────┐  │
│  TerminalComponent  │                             │  │ 文件系统 API   │  │
│  TerminalService    │                             │  │ (fs模块)      │  │
└─────────────────────┘                             │  ├──────────────┤  │
                                                    │  │ PTY 终端管理  │  │
                                                    │  │ (node-pty)   │  │
                                                    └──────────┬─────────┘
                                                               │
                                                      ┌────────▼─────────┐
                                                      │  本地操作系统      │
                                                      │  (文件系统/Shell)  │
                                                      └──────────────────┘
```

### 2.1 工作流程

```
用户导入本地文件夹 → AddProjectComponent 构建 AstTreeNode 树 → 所有节点 isLocal = true

  ├──► ContentComponent 检测根节点 isLocal
  │      ├── true  → 连接本地代理 Agent(ws://127.0.0.1:9120)，文件操作走本地 WS 协议
  │      └── false → 连接远程服务器(现有 /api/storage/ws)，保持现有行为

  └──► TerminalComponent 检测 isLocal
         ├── true  → 连接本地 Agent PTY，终端数据走本地 WS
         └── false → 创建远程 PTY(现有 /terminals/{pid})
```

## 3. 本地代理 Agent 设计

### 3.1 技术选型

| 组件 | 技术 |
|------|------|
| 运行时 | Node.js (>= 18 LTS) |
| WebSocket 服务 | `ws` 库 |
| PTY 支持 | `node-pty`（跨平台伪终端） |
| 分发方式 | npm 全局包 / pkg 打包为可执行文件 |

### 3.2 启动方式

```
luxio-agent --port 9120 --workspace "C:/Users/xxx/my-project"
```

### 3.3 WebSocket 协议

Agent 监听单一端口 `9120`，通过 WebSocket 统一处理文件操作和 PTY 终端连接。

#### 3.3.1 连接标识

客户端连接后发送 `type` 标识消息：

```json
// 文件操作连接
{ "type": "file-service" }

// PTY 终端连接
{ "type": "pty", "cols": 80, "rows": 24, "cwd": "C:/Users/xxx/my-project" }
```

#### 3.3.2 文件操作协议

与 `content.component.ts` 现有 `WebSocketRequest` / `WebSocketResponse` 接口兼容：

```typescript
// Request（与现有协议兼容，扩展 action 类型）
interface LocalFileRequest {
  action: 'listDir' | 'readFile' | 'writeFile' | 'deleteFile'
        | 'createFile' | 'createDir' | 'rename' | 'stat' | 'exists';
  path: string;        // 相对于 workspace 或绝对路径
  content?: string;    // writeFile 时使用
  newName?: string;    // rename 时使用
  requestId?: string;
}

// Response（与现有协议一致）
interface LocalFileResponse {
  type: string;
  success: boolean;
  requestId?: string;
  data?: any;
  message?: string;
}
```

#### 3.3.3 PTY 终端协议

- 使用 xterm.js `AttachAddon` 兼容的**双向 raw 数据流**
- 客户端 → Agent：键盘输入数据（UTF-8）
- Agent → 客户端：PTY 输出数据（UTF-8）
- 尺寸调整：`{ "type": "resize", "cols": 80, "rows": 24 }`

### 3.4 Agent 核心实现

```
luxio-agent/
├── package.json
├── src/
│   ├── index.ts           # 入口，CLI 参数解析
│   ├── server.ts          # WebSocket 服务器，消息路由
│   ├── file-service.ts    # 文件操作（readdir/readFile/writeFile 等）
│   ├── pty-manager.ts     # PTY 生命周期管理（node-pty）
│   ├── protocol.ts        # 类型定义与校验
│   └── security.ts        # 路径安全检查（防遍历）
```

### 4.2 TerminalComponent 改造

**文件：** `src/app/shared/terminal/terminal.component.ts`

```typescript
private async connectLocalPty(): Promise<void> {
  const ws = new WebSocket('ws://127.0.0.1:9120');
  ws.onopen = () => {
    ws.send(JSON.stringify({
      type: 'pty',
      cols: this.terminal.cols,
      rows: this.terminal.rows,
      cwd: this.getLocalProjectPath()
    }));
    this.attachAddon = new AttachAddon(ws);
    this.terminal.loadAddon(this.attachAddon);
  };
  // resize 发送 { type: 'resize', cols, rows }
}
```

## 5. 安全措施

| 风险 | 措施 |
|------|------|
| 端口暴露 | Agent 仅监听 `127.0.0.1`，不绑定 `0.0.0.0` |
| 路径遍历 | `path.normalize()` + 校验是否在 workspace 范围内 |
| 未授权访问 | Agent 可验证 Origin 头或要求 Bearer Token |
| 文件越权 | 限制文件操作范围在指定 workspace 目录内 |

```typescript
function validatePath(basePath: string, requestedPath: string): string {
  const resolved = path.resolve(path.join(basePath, requestedPath));
  if (!resolved.startsWith(path.resolve(basePath))) {
    throw new Error('Path traversal denied');
  }
  return resolved;
}
```
